# TC-HI 软五层一致性状态预警 v13.8

## 方法

- 不使用分组交叉验证。
- 不把试样最终标签硬复制到窗口或层。
- 训练集拟合试样级异常类型校准器，验证集选择融合参数，内推/外推测试集锁定后一次评价。
- 局部窗口/层 TC-HI 概率与五层试样上下文采用软 Potts/CRF 对数意见池融合。

二分类软一致性：

\[
\operatorname{logit}(p_i^*)=(1-\lambda_b)\operatorname{logit}(p_i)
+\lambda_b\operatorname{logit}(p_S)
\]

异常类型软一致性：

\[
r_i^*(c)\propto r_i(c)^{1-\lambda_t}\widetilde r_S(c)^{\lambda_t}
\]

验证集选择结果：\(\lambda_b=0.40\)、\(\lambda_t=0.75\)、类型温度 \(T=0.01\)。
