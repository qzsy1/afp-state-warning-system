# 新数据集采集方案 v11.3：模拟联调包

本目录依据工作区中的 `数据采集计划_v11.md`、`采集字段定义_v11.csv`、`工艺参数状态标签_v11_2.csv` 和 `计划数据集/采集清单模板_v11_3.csv` 生成。

## 内容

- `manifest.csv`：32个工况、每工况2个独立试样、每试样5层，共64个试样和320个层文件。
- `raw/`：每层96点、10 Hz的模拟采集CSV。
- `simulator_stream.csv`：可视化系统“模拟采集”驱动的默认输入。
- `models/i_modern_tcn_new_collection_v11_3.pth`：在模拟训练集上实际训练的I-ModernTCN 24→24模型。
- 同名`.pth.json`：模型输入/输出、4个工艺上下文列和训练集标准化参数。
- `models/training_history.csv`：训练与验证损失。
- `models/test_metrics.json`：固定验证、内推测试和外推测试预测误差。
- `dataset_generation_metadata.json`：模拟机理、随机种子、数据量和划分统计。

## 重要边界

模拟数据显式包含设定温度与速度对热历程、压实力对接触压力、PID角度对接触/张力、层间蓄热对温度的影响。它用于检查：

`采集 → 保存 → 24点输入 → I-ModernTCN未来24点预测 → 健康指标接口`

它不是实测数据，不是缺陷真值，也不能用于宣称真实AFP状态预警准确率。正式采集后应使用相同字段与固定试样划分重新训练模型。
