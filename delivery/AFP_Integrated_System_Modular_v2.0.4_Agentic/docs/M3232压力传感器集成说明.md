# M3232 薄膜压力传感器集成说明

## 当前实现

- 独立接口标识：`m3232_pressure`。
- 厂家操作说明书给出的串口波特率：115200，8N1；设备侧支持自动 X/Y/零点校准。
- 软件将有效压力像素（值大于 5）计算为标量 `薄膜压力`，并进行 9 点中值滤波。
- `压力` 保留给松下 PLC 的过程压力；它与 `薄膜压力` 是两个不同的采集通道和两个不同的接口。
- 同时保留 `压力峰值`、`压力接触面积` 和 `压力有效像素比例` 作为诊断量。
- 解析器支持分片到达的 JSON 矩阵：裸矩阵数组，或 `{"matrix": ...}`、`{"data": ...}`、`{"values": ...}`。
- 行列数默认自动识别，也可以在接口配置中指定 `matrix_rows`、`matrix_cols`。

## 模拟测试文件

`F:\AFP_Capture\simulation_m3232_new_collection\SIM_PRESSURE_M3232_new_collection.csv`

这份文件包含新采集方案的全部通道（包括 `压力` 和 `薄膜压力`）、工艺参数、试样/铺层元数据以及压力矩阵诊断列，可直接用于模拟采集链路测试。它是确定性合成数据，不是真实传感器数据，也不能作为缺陷证据。

## 硬件验证边界

厂家资料没有公开串口数据帧格式。当前 JSON 矩阵解析路径用于模拟和协议探测，不能据此宣称已经完成真实 M3232 硬件通讯验证。接入实物后应：

1. 在软件中选择 `M3232薄膜压力（115200，矩阵自动识别）`，填写实际 COM 口。
2. 检查串口是否打开、是否持续收到数据，以及矩阵行列是否稳定。
3. 保存一小段原始串口字节流，确认厂家实际帧格式；如不是 JSON，再将厂家帧解码器加入独立模块。
4. 用零点、已知载荷和重复加载三项检查标量压力、峰值与接触面积。
