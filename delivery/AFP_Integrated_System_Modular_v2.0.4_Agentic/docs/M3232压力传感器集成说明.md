# M3232 薄膜压力传感器集成说明

## 当前实现

- 独立接口标识：`m3232_pressure`。
- 厂家操作说明书给出的串口波特率：115200，8N1；设备侧支持自动 X/Y/零点校准。
- 软件将有效压力像素（值大于 5）计算为标量 `薄膜压力`，并进行 9 点中值滤波。
- `压力` 保留给松下 PLC 的过程压力；它与 `薄膜压力` 是两个不同的采集通道和两个不同的接口。
- 同时在逐通道质量元数据中保留 `pressure_peak`、`contact_area` 和 `valid_pixel_fraction` 诊断量。
- 解析器支持分片到达的 JSON 矩阵：裸矩阵数组，或 `{"matrix": ...}`、`{"data": ...}`、`{"values": ...}`。
- 行列数默认自动识别，也可以在接口配置中指定 `matrix_rows`、`matrix_cols`。

## 模拟测试文件

`F:\AFP_Capture\simulation_m3232_new_collection\SIM_PRESSURE_M3232_new_collection.csv`

这份文件包含新采集方案的全部通道（包括 `压力` 和 `薄膜压力`）、工艺参数、试样/铺层元数据以及压力矩阵诊断列，可直接用于模拟采集链路测试。它是确定性合成数据，不是真实传感器数据，也不能作为缺陷证据。

## 硬件验证边界

厂家资料没有公开串口数据帧格式。当前 JSON 矩阵解析路径用于模拟和协议探测，不能据此宣称已经完成真实 M3232 硬件通讯验证。接入实物后应：

1. 在软件中选择 `M3232薄膜压力（115200，矩阵自动识别）`，填写实际 COM 口。
2. 检查串口是否打开、是否持续收到数据，以及矩阵行列是否稳定。
3. 保存一小段原始串口字节流，确认厂家实际帧格式；如不是 JSON，再将厂家帧解码器加入独立模块。
4. 用零点、已知载荷和重复加载三项检查标量压力、峰值与接触面积。
## 安全原始抓帧与协议状态

当前仅确认 M3232 默认波特率信息，尚未取得能够证明开始/停止命令、帧边界、校验和压力换算的实物证据。因此交付版遵循以下失败关闭规则：

- 驱动默认**不发送** `begin`、`end` 或任何猜测命令；只有现场确认后的显式版本化配置才可提供命令。
- JSON 矩阵只属于协议仿真输入。即使能得到数值，接口状态仍为 `hardware_protocol_unverified`，不能解除正式五设备门禁。
- 规范主通道固定为 `薄膜压力`；峰值、接触面积和有效像素比例只存在于通道质量元数据，不得覆盖 PLC 的 `压力`。

只读抓帧可通过 Python 调用 `acquisition.capture_m3232_raw_serial("COM8", 输出JSON路径, duration_seconds=10)`。该入口只接受明确的 Windows `COM` 端点，记录原始字节的 Base64、分块时间、端点、波特率、总字节数和 SHA-256，不发送命令，也不导出密码、令牌或数据库凭据。

现场选择端点时必须先在设备管理器核对硬件身份：

- 蓝牙虚拟 COM 只能作为蓝牙传输证据，不能自动认定为 M3232。
- USB 转串口 COM 必须同时记录转换器身份和下游 M3232 身份。
- 只有绑定真实 M3232、当前交付修订和已知安全交互流程的抓帧，才可用于后续版本化二进制解析器。
