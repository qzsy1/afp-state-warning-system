# 网页本机采集辅助系统与本地 MySQL 设计

## 目标

让公网网页在获得授权后，通过访问者电脑上运行的本地采集辅助程序，访问该电脑的 USB HID、UVC、串口和网卡接口，执行与原 EXE 一致的传感器采集、CSV 保存和 MySQL 写入；访客模式继续使用模拟数据，不读取真实硬件。

## 约束与边界

- 普通浏览器不直接枚举访问者的 COM、USB、UVC、PLC、ABB，也不直接连接访问者的 MySQL。
- 本地辅助程序运行在访问者电脑上，硬件和 MySQL 均以该电脑为准。
- 公网网页负责界面、授权、命令和状态展示；辅助程序负责本地硬件、文件和数据库操作。
- 原有本地 EXE 的采集、通道、文件夹层级、命名和数据库写入逻辑作为唯一业务基准。
- 主程序交付 EXE 保持单一目标；辅助程序是明确独立的新组件，不复制生成主程序。
- 每个阶段必须先有自动测试，再做网页实测，未通过不得进入下一阶段。

## 组件

### 网页/服务端

- 保留现有公网 HTTPS 入口和授权会话。
- 增加辅助程序配对、在线状态、能力查询、命令转发和事件接收。
- 不保存辅助程序传回的 MySQL 密码和原始硬件数据日志。
- 模型诊断只接收结构化状态、异常和必要的采样摘要。

### 本地采集辅助程序

- Windows 独立程序，使用现有采集模块和保存模块。
- 通过出站 WSS 连接服务端，避免要求访问者开放入站端口。
- 配对后提供接口发现、协议检查、传感器采集、停止采集、保存和 MySQL 预检能力。
- 本地保存数据库凭据，命令中只传递配置引用或短时加密载荷，不写入服务端日志。

## 接口映射

| 逻辑接口 | 传感器 | 实际接口 | 协议 |
|---|---|---|---|
| 1 | SMRFCT08B 八通道热电偶 | USB HID | SMRF/HID |
| 2 | PLC 过程量 | 网卡 | Modbus TCP |
| 3 | BSV UVC 温度 | USB/UVC | UVC |
| 4 | ABB 机器人 | 与 PLC 共用网卡 | ABB RWS |
| 5 | M3232 薄膜压力 | 串口 COM | M3232 串口协议 |

仅 PLC 与 ABB 允许共用网卡；其它接口必须唯一且协议兼容。接口存在、驱动可用、传感器有数据、采集正常分开显示。

## MySQL 流程

1. 辅助程序检测服务进程/端口。
2. 执行 TCP 握手和 `SELECT 1`。
3. 检查目标数据库和 AFP 表结构。
4. 用事务执行最小写入回滚测试。
5. 通过后，按原 EXE 逻辑批量写入；失败时保留本地 CSV 和待补写记录。

网页 MySQL 状态必须区分服务未启动、端口错误、认证失败、数据库不存在、权限不足、驱动缺失和写入失败。

## 模式

- 访客模拟：只读取导入的 CSV/Excel/文件夹，点击开始后才运行；可保存到访问者授权的本地文件夹。
- 授权真实：必须检测到已配对辅助程序；由辅助程序发现并使用访问者电脑上的真实接口和传感器。
- 切换模式时分别重建状态，禁止真实硬件状态泄漏到模拟模式。

## 诊断

本地规则先输出确定性检查结果；授权且 API Key、模型名称有效时再进行模型增强。模型仅可读取配置、日志和采样摘要等诊断工具，不能直接控制硬件。缺少配置、调用失败或超时时保留本地结果并明确标记回退原因。

## 分阶段验收

1. MySQL 预检与连接诊断：Workbench、辅助程序和原 EXE 均能验证同一数据库。
2. 辅助程序接口发现：USB HID、UVC、COM、网卡及 PLC/ABB 共享规则正确。
3. 模拟模式回归：导入、开始采集、预测、预警和本地保存不受真实接口影响。
4. 本地辅助程序真实采集：无传感器时给出明确状态，正常接口可持续采集。
5. 本地 CSV/MySQL 保存：目录层级、命名、字段和原 EXE 一致。
6. LangChain 诊断：本地结果、模型增强结果和失败回退均可验证。

每一阶段完成后提交 Git，并保留可回退版本；只有当前阶段验收通过才开始下一阶段。
