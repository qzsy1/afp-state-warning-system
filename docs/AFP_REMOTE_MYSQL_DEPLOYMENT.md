# AFP 两台电脑远程 MySQL 部署

## 目标

一台电脑作为 MySQL 数据库服务器，另一台电脑运行 AFP 采集软件。采集软件把每个完整铺层先保存到本地 CSV，再通过目标 MySQL 连接写入服务器数据库；网络短暂中断时不会阻塞采集，恢复后可以补传。

## 服务器电脑

1. 给服务器电脑设置固定局域网 IP。
2. MySQL 监听服务器局域网地址，不要只监听 `127.0.0.1`。
3. Windows 防火墙只允许采集电脑或 VPN 网段访问 TCP 3306。
4. 在 AFP 软件的“目标 MySQL”区域填写数据库名、账号、密码和允许的客户端主机，点击“生成目标授权 SQL”。
5. 使用服务器管理员账号执行生成的 SQL 文件。

生成脚本会创建数据库和 `afp_app` 账号，并授予该数据库所需的表、视图、索引、外键和数据写入权限。它不会给日常账号授予创建任意数据库的全局权限。

## 采集电脑

在“保存到目标电脑 MySQL”中填写：

- 目标地址：服务器电脑 IP；
- 端口：通常为 `3306`；
- 目标用户：管理员执行脚本创建的日常账号；
- 目标密码：脚本中设置的密码；
- 目标数据库：脚本中设置的数据库名称。

点击“测试目标连接”，确认成功后点击“刷新目标关系表”。如果关系结构为空，刷新会自动补齐 AFP 表、视图、索引和外键。

开始采集后勾选目标保存。采集停止并完成一层保存后，软件会把该层上传到目标数据库。目标数据库不可用时，仍保留本地 CSV，并生成待补传记录。

## 错误判断

| 错误码 | 含义 | 处理 |
|---|---|---|
| 1045 | 用户名/密码错误，或没有匹配的用户主机记录 | 检查 `用户@主机` 和密码 |
| 1044 | 账号登录成功，但无目标数据库权限 | 为该数据库执行 `GRANT` |
| 1049 | 数据库不存在 | 执行授权脚本或先创建数据库 |
| 1130 | 目标 MySQL 不允许当前客户端主机 | 修改允许访问的主机并刷新权限 |
| 2003 | 网络、端口、防火墙或监听地址问题 | 检查服务器 TCP 3306 |

数据库名称相同不代表账号相同。本机 `root` 和目标电脑 `afp_app` 是两套独立账号，密码和权限也独立。
