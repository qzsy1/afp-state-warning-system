通过健康检查的模块为：`drivers`、`acquisition`、`storage`、`data_integration`、`prediction`、`health`、`warning`、`training`、`diagnostics`。驱动模块确认打包目录含 `BsvUvcNative.dll` 和 `libusb-1.0.dll`；存储模块确认软件内包含 MySQL Python 驱动；健康指标模块确认新数据方案为 16 个传感器且健康指标工件存在。

## 科学与现场验证边界

- 本次完整链路使用模拟采集数据，未连接真实传感器，因此只能确认真实采集驱动、接口映射和错误处理代码已被装入，不能替代设备现场通信验收。
- 本次未向用户的正式 MySQL 数据库写入测试数据，避免污染实验数据库；已确认数据库驱动可装载。部署时仍需使用实际地址、账户、权限和数据库执行连接及事务测试。
- 一轮训练仅用于证明“导入—整合—训练—保存”链路能够执行，所得验证分数不是论文模型精度，也不能作为真实 AFP 缺陷识别能力结论。
- 当前预警输出属于模型/健康指标证据。没有独立缺陷检测或力学性能证据时，不应把它表述为已确认真实缺陷诊断。
