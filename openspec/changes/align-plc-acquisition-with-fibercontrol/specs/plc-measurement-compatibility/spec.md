# Spec Delta

## Purpose

定义 AFP 与指定参考上位机在 PLC 温度、压力和张力测量上的兼容行为，统一有效数值、负压力处理、来源时间与跨执行模式证据，同时保留故障质量标记，使显示、保存和模型消费的数据可以核对且不丢失原始测量依据。

## ADDED Requirements

### Requirement: PLC 测量保持已确认的寄存器语义

系统 SHALL 按配置端点和 Unit ID 使用 Modbus TCP FC03 读取 PLC 测量。默认站号为 255，默认温度 DT28/29、压力 DT37/38、张力 DT23/24，两个寄存器按低字在前解码为 float32 并保留两位小数。系统 MUST 保留显式映射和工业网卡绑定，不引入无依据的倍率、偏置或三点平均。

#### Scenario: 合法正值按参考语义输出

- **WHEN** 配置映射的寄存器分别编码温度 102.25、压力 123.456、张力 12.75 的 float32 值
- **THEN** 系统 MUST 输出温度 102.25、压力 123.46 N、张力 12.75，并保留对应寄存器地址与原始字

#### Scenario: 显式映射与未选通道

- **WHEN** 使用有效的自定义寄存器映射或只选择部分测量通道
- **THEN** 系统 MUST 使用实际配置地址并只报告实际取得的通道，不伪造缺失通道、不覆盖协议端点或网卡绑定

### Requirement: 负压力规范化必须可追溯

真实 PLC `压力/N` SHALL 在合法有限解码和两位小数处理后将负值规范为 0，并同时保存原始两个寄存器、未裁剪有限值、规范值及处理标识。温度、张力、其他设备和回放数据 MUST NOT 因通道名称相似被执行该处理。

#### Scenario: 负压力保留原始依据

- **WHEN** DT37/38 编码 -2.5 N 且协议有效
- **THEN** 实时规范压力 MUST 为 0 N，来源记录 MUST 能还原 -2.5 和原始两个字，并明确这是负值规范化而非通信失败或有效载荷标定结论

#### Scenario: 合法零值与其他通道负值

- **WHEN** PLC 压力编码合法 0，温度或张力编码合法负值
- **THEN** 压力 MUST 保持有效 0，温度或张力 MUST 保留其按配置解码的负值，且不得产生误截零标识

### Requirement: 故障不得伪装为有效压力零值

系统 SHALL 保留严格 Modbus 协议校验及现有质量与新鲜度规则。协议错误、通信失败、非有限数值和过期样本 MUST NOT 转为有效 0 或新测量；允许的新鲜度内沿用 MUST 保留旧来源时间与沿用质量。故障证据 MUST 以严格 JSON 安全的形式保存，不能输出 NaN/Infinity 数字。

#### Scenario: 非有限压力与异常响应

- **WHEN** 压力位模式为 NaN/Infinity，或事务、Unit ID、功能码、长度、数量不符，或返回 Modbus 异常
- **THEN** 系统 MUST 标记相应错误及未通过状态，不产生新的有效压力，保留可用原始字和错误分类，不能将接口判为全部就绪

#### Scenario: 暂无新样本与超时

- **WHEN** 当前周期没有新压力且已有样本仍在新鲜度内，随后超过新鲜度
- **THEN** 系统 MUST 先按既有规则输出带旧来源关联的沿用值，过期后输出空值及陈旧或缺测质量，不能把旧值重新编号为新测量

### Requirement: PLC 采样使用独立的 100 ms 周期与实际来源时间

默认真实 PLC 接口 SHALL 在独立于其他设备的生命周期中按温度、张力、压力顺序分别读取，每通道请求两个寄存器，目标轮次周期为 100 ms。慢轮次 MUST 跳过已过截止时间，不重入或突发补读；各通道 MUST 具有实际来源序号和完成时间，不能倒填到早于接收的统一帧。

#### Scenario: 正常周期与读取顺序

- **WHEN** 三通道按默认地址启用且每轮读取可在 100 ms 内完成
- **THEN** 请求 MUST 按 DT28 两字、DT23 两字、DT37 两字排列，连续轮次按 100 ms 目标调度，实际来源时间和观察周期 MUST 可核对

#### Scenario: 慢读与其他接口并行

- **WHEN** 一轮 PLC 读取超过目标周期或发生通信故障
- **THEN** 系统 MUST 记录超时或跳过周期，保持有界恢复、状态查询和停止，其他设备 MUST 继续按其合同采集，不得因 PLC 等待被共享阻塞

#### Scenario: 压力在统一帧截止后到达

- **WHEN** 温度、张力和压力分别在不同时间完成且压力晚于某帧截止时间
- **THEN** 该帧 MUST NOT 使用尚未接收的压力，新压力只能进入其实际来源时间之后适用的帧

### Requirement: 展示与持久化使用同一规范测量和来源关联

实时曲线、主 CSV、MySQL 和模型入口 SHALL 使用同一规范 PLC 测量并遵守既有质量准入。主列名、单位及模型维度 MUST 保持兼容；来源记录和时间戳侧车 MUST 持久化原始字、解码值、规范值、处理档与源关联，能够区分截零、沿用、缺测和有效零。旧文件 MUST 保持可读且不重写。

#### Scenario: 负压力贯穿显示与保存

- **WHEN** 一个有效负压力样本被规范为 0 并进入统一帧
- **THEN** 各消费端 MUST 使用相同规范值，保存来源 MUST 对应同一个源样本的原始负值，不得引用写盘时较新的驱动记录；模型仍须满足其原有质量及通道准入

#### Scenario: 旧文件与无效样本

- **WHEN** 读取没有新增来源字段的历史文件或保存故障期间的数据
- **THEN** 系统 MUST 保持历史文件可读，不重新解释其数值；故障样本 MUST 保留空值或质量信息，不以有效零补齐保存或模型输入

### Requirement: 两种真实执行模式保持测量合同一致

本机直连、远程 helper、连接检查及只读采集复现 SHALL 使用相同测量档、配置和来源语义。远程 helper 不能提供该合同及必要证据时 MUST 明确拒绝该采集请求，不丢弃新增证据、不回退服务器本机设备。公共数据权限 MUST 不因来源证据扩展而放宽。

#### Scenario: 相同样本在两种模式采集

- **WHEN** 本机与 helper 路径收到相同寄存器、来源时间、序号及故障序列
- **THEN** 两种路径 MUST 产生等价的规范值、质量、来源记录和保存关联

#### Scenario: helper 不支持兼容测量

- **WHEN** helper 未声明所需能力或无法保留必要来源字段
- **THEN** 真实采集 MUST 返回明确的不兼容错误并阻止启动，不得以旧算法或缺少证据的值声称兼容

### Requirement: 软件兼容与实物数据一致性分别验收

软件 SHALL 通过生产路径的寄存器、数值、时序、故障、模式及保存验证，再按受控流程更新唯一正式运行目录并从该目录复验。实物一致性 SHALL 以稳定载荷、双方原始寄存器、时间、配置和参考依据核对；未取得现场证据 MUST 不宣称量值精度、偏差根因或最终实物验收通过。

#### Scenario: 软件检查通过而现场条件缺失

- **WHEN** 自动化与正式目录软件复验通过，但无法取得批准工况的原始寄存器对照
- **THEN** 软件交付与“实物数据一致性待验证” MUST 分别报告，不能将夹具结果当作现场结论

#### Scenario: 正常正压力持续不一致

- **WHEN** 同一稳定工况下两程序的正常正压力仍持续偏移
- **THEN** 系统 MUST 保留实际原始字、来源时间和设备配置用于定位，不自动添加倍率或零点修正，也不将版本差异直接认定为根因
