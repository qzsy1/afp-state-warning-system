# Spec Delta

## Purpose

定义无传感器双机部署检查、操作员现场顺序、脱敏证据导出和最终真实设备验证边界，使外部环境阻塞与物理设备待验收项目保持清晰可执行。

## ADDED Requirements

### Requirement: 第二台Windows电脑必须具有一键检查入口
系统 SHALL 提供可复制到第二台 Windows 电脑直接执行的一键脚本，检查 Helper 安装、启动、停止、重启、候选身份、配对、readiness、能力、HTTP/WebSocket、端口和环境设置。

#### Scenario: 第二台电脑可访问
- **WHEN** 操作员在目标电脑执行脚本并提供候选包及非秘密连接参数
- **THEN** 脚本 MUST 生成机器可读和人可读报告，并验证 Helper 完整生命周期

#### Scenario: 第二台电脑不可访问
- **WHEN** 当前环境无法访问目标电脑
- **THEN** 双机项目 MUST 报告 `blocked`，同时交付可在目标电脑离线执行的脚本和说明

### Requirement: 双机无传感器验证必须执行真实网络路径
真实双机检查 SHALL 使用第二台电脑上的 Helper 和模拟源验证 10 Hz、ACK、批量、重传、停止、对账、临时断网、Helper 重启、重复命令、睡眠恢复和网络切换。

#### Scenario: 完成真实双机模拟源演练
- **WHEN** 两台 Windows 电脑和网络可用但未连接传感器
- **THEN** 报告 MUST 区分真实跨机传输证据与模拟传感器输入，并记录两端候选身份和时钟状态

#### Scenario: 使用本机临时服务器
- **WHEN** 所有进程运行在同一台电脑
- **THEN** 结果 MUST 仅为本机协议模拟，不得满足真实双机检查

### Requirement: 现场运行手册必须规定唯一操作顺序
现场操作包 SHALL 用简洁步骤覆盖安装候选包、预检、选择模式、修复失败、启动、观察质量/队列/网络/保存、正常停止、数据库重试/对账和证据导出。

#### Scenario: 操作员首次部署
- **WHEN** 操作员按照手册从空目录安装候选包
- **THEN** 每一步 MUST 指向一个一键入口、预期状态、失败修复建议和继续条件

#### Scenario: 预检未通过
- **WHEN** 任一必需项目为 `failed` 或 `blocked`
- **THEN** 手册 MUST 禁止进入正式采集，并指导重新检查而不是绕过门禁

### Requirement: 证据导出必须脱敏且完整
系统 SHALL 导出包含候选摘要、配置摘要、预检、演练、对账、系统状态和日志索引的证据包，MUST 排除密码、Token、凭据、未经脱敏的设备路径及机器秘密。

#### Scenario: 导出现场证据
- **WHEN** 操作员运行证据导出入口
- **THEN** 工具 MUST 先执行秘密扫描，生成内容清单和摘要，并在发现敏感值时失败关闭

#### Scenario: 外部环境项目阻塞
- **WHEN** 第二台电脑、目标 MySQL、管理员权限或网络访问不可用
- **THEN** 证据包 MUST 列出阻塞原因、已完成替代证据、证据等级和需要用户提供的环境

### Requirement: 最终清单只能保留真实设备事项
“仅剩真实设备验证清单” SHALL 只包含实物身份/端口、通道完整性、已知输入下的单位/量程/倍率/大小端/方向、校准/零点/噪声/漂移/串扰、全设备 10 Hz、USB 供电/带宽/电磁环境、真拔线/断电/设备重启、真实驱动关闭和实物耐久。

#### Scenario: 生成最终清单
- **WHEN** 所有可执行的软件和环境准备检查完成
- **THEN** 清单 MUST 逐项限于真实设备物理特性，并引用对应现场验收方法

#### Scenario: 清单含环境问题
- **WHEN** 清单仍出现版本、配置、网络、存储、MySQL、Helper 部署或 Windows 设置问题
- **THEN** 生成门禁 MUST 失败并把该项移回未完成或阻塞报告，不得宣称传感器前准备完成

### Requirement: 高影响环境变更必须保持可审查
准备工具 SHALL 对管理员权限、正式发布、生产防火墙和生产网络设置只执行检测并生成可审查脚本；未经明确授权 MUST NOT 自动实施变更。

#### Scenario: 防火墙规则缺失
- **WHEN** 预检发现需要生产防火墙变更
- **THEN** 工具 MUST 输出拟议规则、影响和回滚方式并标记 `blocked`，不得自动应用

#### Scenario: 正式发布被请求
- **WHEN** 候选包通过但没有正式发布授权
- **THEN** 工具 MUST 保留候选目录并报告正式 `delivery` 未改变，不得自动替换正式发布

### Requirement: 公网入口必须以独立公共边缘证据失败关闭
公网入口预检 SHALL 分别验证本地源站、隧道控制面、公共 DNS 和公共边缘数据面。公共边缘探测 MUST 绕过系统代理，使用公共 DNS 返回的全局可路由 A 或 AAAA 地址，并携带原公网域名的 TLS SNI/Host。对公网域名的同机普通请求 MUST NOT 被计为公网可达证据。

#### Scenario: DNS返回非全局地址
- **WHEN** 公共 DNS 只返回回环、私有、链路本地、运营商级 NAT、文档、基准测试、组播、保留或其他非全局可路由地址
- **THEN** 公共边缘检查 MUST 报告 `failed` 或 `blocked`，不得写入 `online`，不得允许双机采集步骤继续

#### Scenario: 公共边缘返回重定向或非200
- **WHEN** 强制公共边缘请求返回重定向或任意非 HTTP 200 状态
- **THEN** 公共边缘检查 MUST 失败且不得跟随重定向形成通过结论

#### Scenario: 强制公共边缘探测成功
- **WHEN** 探测绕过代理、强制连接全局可路由边缘地址、保持原域名 TLS SNI/Host，并获得精确 HTTP 200 和匹配的静态身份
- **THEN** 公共边缘数据面 MAY 通过，报告 MUST 将该证据与本地源站、隧道控制面和普通域名请求分开记录

### Requirement: 公网入口必须具有持久化代次和原子状态
系统 SHALL 持久化公网入口 URL、提供方、恢复所有者、候选身份、分层健康结果和单调递增的入口代次。URL、提供方或恢复所有者变化时 MUST 原子发布新代次；损坏、缺失或回退的状态 MUST 失败关闭。

#### Scenario: 原子发布新入口代次
- **WHEN** 新入口的源站、控制面、公共 DNS、强制公共边缘 HTTP 200 和静态身份全部通过
- **THEN** 系统 MUST 使用同目录临时文件和原子替换发布完整新状态，并在复读一致后才把新入口视为当前入口

#### Scenario: 状态发布失败
- **WHEN** 状态写入、刷新、原子替换或复读验证失败
- **THEN** 当前入口代次和恢复所有者 MUST 保持不变，新入口不得被标记为 `online`

#### Scenario: 服务器重启读取入口状态
- **WHEN** 服务器进程重启
- **THEN** 系统 MUST 从持久化入口状态恢复代次和所有者，不得从当前 PID、普通 HTTP 成功或临时连接自行推导新代次

### Requirement: 入口代次变化必须废止旧客户端状态和命令
配对、Helper readiness、WebSocket 会话和采集命令 SHALL 绑定公网入口代次。发布新代次时，系统 MUST 废止旧代次客户端状态，断开旧会话，并将旧代次未交付或未确认的采集命令置为明确失败终态。

#### Scenario: URL变化后存在旧排队启动命令
- **WHEN** 新入口代次发布时旧代次仍有排队或未确认的启动采集命令
- **THEN** 命令 MUST 终结为 `ingress_generation_changed`，MUST NOT 被投递、重标记到新代次或自动重试

#### Scenario: 旧Helper会话尝试继续工作
- **WHEN** Helper 使用旧代次会话报告 readiness、轮询命令或提交结果
- **THEN** 服务器 MUST 拒绝该操作并要求使用当前入口重新连接和配对，且不得把 Helper 标记为就绪

#### Scenario: 新代次Helper完成准备
- **WHEN** Helper 使用匹配候选和当前代次重新连接、配对并通过协议与能力检查
- **THEN** 系统 MAY 建立新的 readiness，但不得恢复旧代次命令

### Requirement: 公网入口恢复必须只有一个所有者
公网入口状态 SHALL 指定唯一 `recovery_owner`。只有当前所有者的 watchdog 可以执行自动恢复；其他提供方只能读取并报告状态。提供方或所有者切换 MUST 是明确的操作员切换动作。

#### Scenario: 非所有者watchdog检测到入口异常
- **WHEN** 非当前恢复所有者的 watchdog 发现自身入口可启动或当前入口异常
- **THEN** 它 MUST NOT 启动替代隧道、改写 URL、切换计划任务、关闭当前入口或夺取恢复所有权

#### Scenario: 并发或陈旧切换请求
- **WHEN** 两个切换请求并发执行，或请求所依据的入口代次已经过期
- **THEN** 共享互斥与代次比较 MUST 只允许一个请求继续，其他请求失败关闭且不得改变当前状态

### Requirement: 公网入口切换必须保留回退并具备异常安全
公网入口切换 SHALL 先通过仅本机管理端口取得有界预约。预约建立时 MUST 原子核对进行中的启动、未确认命令、活动采集和未完成对账；预约 MUST 跨服务器进程重启和固定运行目录替换持久存在，并在预约期间拒绝新的本机及 Helper 启动。切换先启动并验证新入口，再原子发布新代次的非在线待提交状态；只有 Helper 候选、哈希、协议、配对和代次 readiness 全部通过后才可提交 `online`，最后才允许在明确切换动作中退出旧入口。安装、健康检查或 watchdog 自检 MUST NOT 自动停止、禁用或删除既有入口。任意失败或异常 MUST 触发高代次回滚并释放预约。

#### Scenario: 存在活动采集
- **WHEN** 当前代次存在已确认执行中的启动命令、活动采集或尚未完成停止与对账的采集
- **THEN** 入口切换 MUST 被阻止并报告活动采集身份，不得通过切换使采集在旧入口孤立运行

#### Scenario: 新入口公共边缘验证失败
- **WHEN** 新入口的源站或控制面可用，但公共边缘探测失败、超时、重定向或无法形成独立证据
- **THEN** 切换 MUST 失败关闭，既有入口、权威代次及恢复所有者 MUST 保持不变

#### Scenario: 发布后发生异常
- **WHEN** 新代次发布后、部署完成或旧入口退出前发生异常
- **THEN** Helper 门通过前发布的状态 MUST 保持非在线并阻止采集启动；可执行补偿时系统 MUST 以高于失败代次的新代次恢复原入口身份和恢复所有者并保留旧入口，如果回滚也失败，MUST 保存两端现场并报告明确失败终态

#### Scenario: 首次入口发布失败且没有旧状态
- **WHEN** 首次入口代次已经发布但后续 Helper 门或提交门失败
- **THEN** 系统 MUST 发布更高代次的非在线墓碑状态，MUST NOT 删除状态文件并在后续重用已经观察过的代次

#### Scenario: 旧入口退役失败
- **WHEN** 新入口和 Helper 门已通过，但退出旧入口返回失败或部分失败
- **THEN** 事务 MUST 先验证旧入口数据面可用，再停止候选入口并以更高代次恢复旧入口身份，且 Helper 层 MUST 保持非在线直至新代次显式对账；旧入口不可用或无法证明补偿完成时 MUST 保留可用候选并报告人工故障态，不得保留新入口 `online` 结论

#### Scenario: 新入口完成切换
- **WHEN** 新入口全部分层门禁通过、状态原子发布并复读一致，当前 Helper 候选、SHA-256、协议、配对和代次 readiness 匹配，且操作员明确批准切换所有者
- **THEN** 部署 MAY 完成并退出旧入口，同时 MUST 保证只有新所有者拥有自动恢复职责

#### Scenario: 候选运行时替换
- **WHEN** 部署事务将已验证候选提升到固定运行目录
- **THEN** 安全存储、Helper 注册状态、目标采集 journal、入口状态和切换预约 MUST 被保留；部署不得以候选目录覆盖这些可变状态，且所有祖先 junction 或 reparse point 的真实路径必须仍位于受控工作区

### Requirement: 公网与Helper状态必须分层报告
系统 SHALL 分别报告源站监听、隧道控制面、公共 DNS、公共边缘、权威 URL/代次/所有者、Helper 任务与进程、候选与哈希、会话代次、配对、readiness 和旧命令终态。总体 `online` MUST 要求所有必要层通过。

#### Scenario: 公网边缘可用但Helper更新失败
- **WHEN** 公共边缘得到精确 HTTP 200，但 Helper 重启、路径、候选、代次、配对或 readiness 任一检查失败
- **THEN** 报告 MUST 保留公网边缘通过证据并把 Helper 层标为失败或阻塞，总体不得写入 `online` 或允许双机采集步骤继续

#### Scenario: 生成脱敏公网证据
- **WHEN** 系统保存入口和 Helper 状态
- **THEN** 证据 MUST 只包含请求元数据、摘要、时间戳和非敏感错误，MUST NOT 包含响应正文、WebSocket 帧、Cookie、Token、配对码或敏感请求头
