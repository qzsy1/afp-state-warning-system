# Spec Delta

## Purpose

定义无传感器双机部署检查、操作员现场顺序、脱敏证据导出和最终真实设备验证边界，使外部环境阻塞与物理设备待验收项目保持清晰可执行。

## ADDED Requirements

### Requirement: 第二台Windows电脑必须具有一键检查入口
系统 SHALL 提供可复制到第二台 Windows 电脑直接执行的一键脚本，检查 Helper 安装、启动、停止、重启、候选身份、配对、readiness、能力、HTTP/WebSocket、端口和环境设置。

#### Scenario: 第二台电脑可访问
- **WHEN** 操作员在目标电脑执行脚本并提供候选包及非秘密连接参数
- **THEN** 脚本 MUST 生成机器可读和人可读报告，并验证 Helper 完整生命周期

#### Scenario: 第二台电脑不可访问
- **WHEN** 当前环境无法访问目标电脑
- **THEN** 双机项目 MUST 报告 `blocked`，同时交付可在目标电脑离线执行的脚本和说明

### Requirement: 双机无传感器验证必须执行真实网络路径
真实双机检查 SHALL 使用第二台电脑上的 Helper 和模拟源验证 10 Hz、ACK、批量、重传、停止、对账、临时断网、Helper 重启、重复命令、睡眠恢复和网络切换。

#### Scenario: 完成真实双机模拟源演练
- **WHEN** 两台 Windows 电脑和网络可用但未连接传感器
- **THEN** 报告 MUST 区分真实跨机传输证据与模拟传感器输入，并记录两端候选身份和时钟状态

#### Scenario: 使用本机临时服务器
- **WHEN** 所有进程运行在同一台电脑
- **THEN** 结果 MUST 仅为本机协议模拟，不得满足真实双机检查

### Requirement: 现场运行手册必须规定唯一操作顺序
现场操作包 SHALL 用简洁步骤覆盖安装候选包、预检、选择模式、修复失败、启动、观察质量/队列/网络/保存、正常停止、数据库重试/对账和证据导出。

#### Scenario: 操作员首次部署
- **WHEN** 操作员按照手册从空目录安装候选包
- **THEN** 每一步 MUST 指向一个一键入口、预期状态、失败修复建议和继续条件

#### Scenario: 预检未通过
- **WHEN** 任一必需项目为 `failed` 或 `blocked`
- **THEN** 手册 MUST 禁止进入正式采集，并指导重新检查而不是绕过门禁

### Requirement: 证据导出必须脱敏且完整
系统 SHALL 导出包含候选摘要、配置摘要、预检、演练、对账、系统状态和日志索引的证据包，MUST 排除密码、Token、凭据、未经脱敏的设备路径及机器秘密。

#### Scenario: 导出现场证据
- **WHEN** 操作员运行证据导出入口
- **THEN** 工具 MUST 先执行秘密扫描，生成内容清单和摘要，并在发现敏感值时失败关闭

#### Scenario: 外部环境项目阻塞
- **WHEN** 第二台电脑、目标 MySQL、管理员权限或网络访问不可用
- **THEN** 证据包 MUST 列出阻塞原因、已完成替代证据、证据等级和需要用户提供的环境

### Requirement: 最终清单只能保留真实设备事项
“仅剩真实设备验证清单” SHALL 只包含实物身份/端口、通道完整性、已知输入下的单位/量程/倍率/大小端/方向、校准/零点/噪声/漂移/串扰、全设备 10 Hz、USB 供电/带宽/电磁环境、真拔线/断电/设备重启、真实驱动关闭和实物耐久。

#### Scenario: 生成最终清单
- **WHEN** 所有可执行的软件和环境准备检查完成
- **THEN** 清单 MUST 逐项限于真实设备物理特性，并引用对应现场验收方法

#### Scenario: 清单含环境问题
- **WHEN** 清单仍出现版本、配置、网络、存储、MySQL、Helper 部署或 Windows 设置问题
- **THEN** 生成门禁 MUST 失败并把该项移回未完成或阻塞报告，不得宣称传感器前准备完成

### Requirement: 高影响环境变更必须保持可审查
准备工具 SHALL 对管理员权限、正式发布、生产防火墙和生产网络设置只执行检测并生成可审查脚本；未经明确授权 MUST NOT 自动实施变更。

#### Scenario: 防火墙规则缺失
- **WHEN** 预检发现需要生产防火墙变更
- **THEN** 工具 MUST 输出拟议规则、影响和回滚方式并标记 `blocked`，不得自动应用

#### Scenario: 正式发布被请求
- **WHEN** 候选包通过但没有正式发布授权
- **THEN** 工具 MUST 保留候选目录并报告正式 `delivery` 未改变，不得自动替换正式发布
