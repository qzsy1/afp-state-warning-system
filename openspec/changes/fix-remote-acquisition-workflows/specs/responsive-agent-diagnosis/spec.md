## Purpose

定义自动诊断在外部大模型响应缓慢或不可用时的即时本地结果、异步模型增强、超时降级、重复结果复用和证据边界，避免界面长时间停留在加载状态。

## ADDED Requirements

### Requirement: 本地诊断必须先行可用
系统 SHALL 在启动模型调用前完成基于当前采集数据、阈值和既有规则的本地事实诊断，并 MUST 将该结果与模型增强任务状态分开返回和显示。

#### Scenario: 外部模型响应缓慢
- **WHEN** 用户启动自动诊断且外部模型尚未返回
- **THEN** 界面 MUST 先显示本地诊断、证据时间范围和“模型增强处理中”状态，用户无需等待模型即可查看本地结果

#### Scenario: 外部模型不可用
- **WHEN** 模型请求超时、认证失败或服务不可达
- **THEN** 已生成的本地诊断 MUST 保持可用，模型部分 MUST 显示明确降级原因且不得伪装为完整模型诊断

### Requirement: 默认快速路径限制外部往返
默认诊断模式 SHALL 使用确定性的本地工具和证据收集后最多一次模型综合调用；需要模型自主规划的深度模式 MUST 为显式选择，并 MUST 不影响默认快速路径。

#### Scenario: 使用默认诊断
- **WHEN** 用户未显式选择深度模式而启动模型增强诊断
- **THEN** 系统 MUST 复用本地已收集证据并最多执行一次外部模型综合调用

#### Scenario: 使用深度诊断
- **WHEN** 用户显式选择深度模式
- **THEN** 系统 MAY 执行模型规划和综合阶段，但 MUST 显示当前阶段并遵守总超时与降级合同

### Requirement: 模型任务必须有分阶段超时和总时限
系统 MUST 对连接、规划和综合阶段设置独立有界超时，默认快速路径的服务器任务总时限 MUST 不超过 90 秒，浏览器等待上限 MUST 不超过 120 秒；超时后 MUST 终止当前任务或忽略迟到结果，并返回已完成的本地事实。

#### Scenario: 综合调用超时
- **WHEN** 默认快速路径的模型综合调用超过配置时限
- **THEN** 任务 MUST 在总时限内结束为降级状态，MUST 不对同一超时阶段立即执行无界重试

#### Scenario: 浏览器轮询结束
- **WHEN** 浏览器达到 120 秒等待上限而任务仍未结束
- **THEN** 浏览器 MUST 停止持续加载并显示本地结果、任务标识和超时状态

### Requirement: 相同异常结果可短期复用
系统 SHALL 按会话、异常证据指纹、模型标识和安全配置摘要短期缓存已完成的模型结果；缓存键和日志 MUST 不包含 API 密钥或原始凭据。

#### Scenario: 重复诊断相同证据
- **WHEN** 同一会话在缓存有效期内以相同异常证据和模型配置再次请求诊断
- **THEN** 系统 SHALL 返回已完成结果并标记命中缓存，不得再次发起等价模型调用

#### Scenario: 新样本改变证据
- **WHEN** 新样本、告警状态或诊断配置改变导致证据指纹变化
- **THEN** 系统 MUST 不使用旧缓存结果，并 SHALL 启动新的增强任务

### Requirement: 诊断证据边界必须保持
模型增强内容 SHALL 与本地计算事实、预测或预警、弱标签或模拟证据和已确认缺陷明确区分，并 MUST 记录各阶段耗时与降级来源以供验收。

#### Scenario: 模型生成故障解释
- **WHEN** 模型返回原因分析或建议
- **THEN** 界面 MUST 将其标记为模型辅助解释，并 MUST 不把预测、模拟数据或未独立验证的异常描述为已确认真实缺陷
