# Design

## Context

参见 proposal.md。设备适配器已有独立线程，管理器通过生命周期锁串行化检测、启动和停止。真实采集的设备打开和持久化准备需要允许状态查询，保持真实采集首样本门禁及文件保存合同。

## Goals / Non-Goals

目标是软件会话内检测一次、正常重复采集无需重检、启动可观察和取消。设备标定、文件格式及实际采样时间语义保持各自合同。

## Decisions

- 管理器保存内存中的检测会话身份与配置指纹；正常停止保留，故障、断线、配置变化及进程重启失效。导入的检测凭证首次使用仍校验有效期，不从磁盘恢复检测授权。
- 提供异步启动任务，复用同步启动核心。任务在后台执行就绪校验和设备打开，操作编号用于重复请求保护、状态关联和取消。取消确认须等待设备释放，期间拒绝新启动。
- 状态锁只保护短状态更新，设备I/O和持久化准备由生命周期锁保护。状态中公开启动阶段、接口状态和已测耗时。
- 完整首次检测并行运行无共享物理资源的接口，汇总后一次性签发整体检测结果，保留单接口错误和通道证据。
- 热电偶完整记录方式须显式绑定到经验证的仪表配置，不全局静默切换。应变固定稳定等待保留，等待缩短须有独立实验支持。
- 停止时先向所有设备请求释放，再按截止时间等待；ESR1001原生USB允许在配置的强制停止预算内完成停止应答，其他设备保留短释放预算。资源释放超时继续阻止下一采集，不将未保存数据标记成功。

## Risks / Trade-offs

- [取消时设备尚在打开] → 将取消信号贯穿打开等待及首样本等待，释放完成前保持取消状态并阻止新会话。
- [缓存检测结果掩盖故障] → 每次启动仍执行真实设备打开、身份和首样本验证，故障立即失效，重新打开软件必须重新检测。
- [并行探针争用端口] → 复用配置冲突校验，按物理资源隔离并发。
- [实机耗时受负载影响] → 分别测量首次准备与正常重复启动，多次取P50/P95，不用页面刷新率冒充硬件更新率。

## Migration Plan

在当前本机任务分支修改并完成软件检查和实机测试；获准发布后按单运行目录流程更新并启动复验。采集实验数据使用 D:\AFP_Capture 的诊断子目录。
