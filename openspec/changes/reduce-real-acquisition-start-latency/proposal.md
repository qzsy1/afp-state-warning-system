# Proposal

## Why

真实设备启动需要可查询、可取消的状态，页面请求超时不能被解释为后台启动失败。正常采集应复用当前软件会话中配置未变化的设备检测结果，避免逐次完整检查和热电偶逐通道首轮读取造成等待。

## What Changes

- 真实采集提供异步启动任务、启动进度及取消，设备I/O不占用状态查询锁。
- 本次软件会话保留检测授权，配置变化、设备故障或重启后失效；正常停止不消耗授权。
- 对独立物理资源并行执行首次检测，资源冲突仍拒绝。
- 使用已实测兼容的热电偶完整记录读取配置，保留其他设备的显式读取方式。
- 显示并测量启动到首帧及所有所选通道就绪的耗时。

## Capabilities

### New Capabilities

- `acquisition-start-lifecycle`: 真实采集启动、取消、会话检测复用及耗时。

### Modified Capabilities

无。

## Impact

影响采集管理器、本机及Helper启动入口、页面采集控制、设备就绪校验和现场热电偶配置；不改变采集文件格式和标定语义。
