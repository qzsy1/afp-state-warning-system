## Purpose

定义任何代码、配置、界面或发布修改都不得破坏的AFP系统核心能力，并明确自动化、本机集成和现场硬件三种验证结论的边界，作为所有后续变更的统一回归基线。

## ADDED Requirements

### Requirement: 核心能力目录必须完整且稳定
系统 MUST 维护一份带唯一需求编号的核心能力目录，至少覆盖软件启动与前端加载、模拟采集、真实采集状态机、接口与传感器映射、边缘辅助程序、CSV保存、MySQL、本地诊断、模型增强诊断、局域网、公网、WebSocket实时数据、17个模型输入通道和M3232薄膜压力通道。

#### Scenario: 修改单一功能时仍执行完整核心回归
- **WHEN** 开发者只修改一个局部功能并请求完整或发布验证
- **THEN** 系统仍 MUST 检查核心能力目录中的全部强制自动化项目，而不是只运行本次变更的测试

#### Scenario: 新增核心能力
- **WHEN** 新功能被确认属于稳定产品能力
- **THEN** 该功能 MUST 获得唯一需求编号、验证方法和所属验证层级后才能进入稳定发布

### Requirement: 模拟采集必须与真实采集状态隔离
模拟采集和真实采集 MUST 使用各自的接口映射与运行状态；从一种模式切换到另一种模式时，不得泄漏运行中标记、接口分配或传感器连接状态。

#### Scenario: 模拟文件导入
- **WHEN** 用户导入或使用默认模拟数据
- **THEN** 系统 MUST 根据数据中存在的通道建立模拟接口与传感器可用状态，并且 MUST 等待用户点击开始采集

#### Scenario: 模式往返切换
- **WHEN** 用户从模拟采集切换到真实采集后再切回模拟采集
- **THEN** 模拟采集界面和通道状态 MUST 仅由当前模拟设置决定，且不得显示残留的真实接口状态

### Requirement: 真实采集接口与传感器关系必须保持
系统 MUST 保持SMRF八通道热电偶、松下PLC、BSV UVC、ABB RWS和M3232薄膜压力传感器的物理接口、协议和通道定义，不得因无关修改删除或混淆这些能力。

#### Scenario: 接口映射回归
- **WHEN** 完整回归检查接口目录和默认映射
- **THEN** 检查结果 MUST 包含SMRF USB HID、PLC Modbus TCP、BSV UVC、ABB RWS和M3232专用串口映射，并明确端口识别不等于有效传感器数据

#### Scenario: 通道完整性
- **WHEN** 回归检查预测输入和采集通道
- **THEN** 系统 MUST 保留17个模型输入通道及独立的M3232薄膜压力数据能力

### Requirement: 保存链路必须保持一致
系统 MUST 保持原有CSV目录层级、命名、权限判定和MySQL保存语义；目录为空、不存在或不可写时不得错误报告为可保存。

#### Scenario: 可写目录
- **WHEN** 保存目录存在且当前进程具有写权限
- **THEN** 系统 MUST 按既有层级和命名保存CSV，并准确显示可保存状态

#### Scenario: 不可写或空目录
- **WHEN** 保存目录为空、不存在或不可写
- **THEN** 系统 MUST 禁止CSV保存并显示真实原因，不得显示绿色可保存状态

#### Scenario: MySQL异常
- **WHEN** 本地或目标MySQL连接、写入或刷新失败
- **THEN** 系统 MUST 返回可诊断错误且不得破坏CSV采集与后续重试能力

### Requirement: 诊断链路必须可降级
本地规则诊断 MUST 能够独立运行；模型配置有效时系统 MUST 在保留本地事实的基础上执行模型增强；模型不可用时不得清空或覆盖本地诊断结果。

#### Scenario: 无模型配置
- **WHEN** API Key或模型名称缺失
- **THEN** 系统 MUST 返回本地规则诊断，并明确模型增强未启用

#### Scenario: 模型失败
- **WHEN** 模型超时、连接失败、工具调用失败或返回结构不完整
- **THEN** 系统 MUST 保留全部本地异常结果、标记模型增强失败并允许用户再次诊断

### Requirement: 验证结论必须标明证据层级
每项回归结果 MUST 标记为自动化验证、本机集成验证、现场硬件验证或未验证，且较低层级结果不得冒充更高层级结论。

#### Scenario: 无真实传感器
- **WHEN** 自动化和模拟测试通过但未连接真实硬件
- **THEN** 报告 MUST 写明软件/模拟验证通过和现场硬件未验证，不得宣称真实采集通过
